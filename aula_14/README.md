# API Casa de Sucos 🥤

Uma API REST desenvolvida em Python (FastAPI) para gerenciar um cardápio de sucos e calcular automaticamente suas informações nutricionais consumindo a API pública **Fruityvice**.

## Tecnologias Utilizadas
- Python 3
- FastAPI
- Uvicorn
- Requests
